Turn Flow (Simplified)

A quick overview of the main loop.

Deploy → Turn Start → Select Unit → Move / Rotate / Attack → Resolve Combat → Switch Turn

Core Features

  • Procedural hex map generation with multiple terrain types (Plains, Forest, Hills, Marsh, Steppe).
  • Terrain-based buffs/debuffs affecting combat stats per unit type.
  • Rotation/facing system (6 directions) with back-attack advantage.
  • Dice-based combat resolution: Attack + d6 vs Defense + d6.
  • Deployment phase with drag & drop unit placement (prototype: Light Infantry).
  • Turn manager controlling action validation and state switching.

Technical Architecture Overview

(Code not public — details provided here to demonstrate systems thinking.)

  • Data-driven design using ScriptableObjects for unit/terrain configs.
  • Centralized turn-state manager (selection → actions → resolution → turn switch).
  • Hex coordinate system + directional facing logic integrated into combat modifiers.
  • Local host-client model for multiplayer synchronization testing.
  • Planned: disconnect handling with save/load recovery.

Systems Design Highlights

  • Rock-paper-scissors counters between unit categories (infantry / cavalry / archers).
  • Facing + terrain creates positional tactics (frontline shaping, flanks, backstabs).
  • Pre-match economy: draft units within a fixed gold budget.
  • Minimal UI philosophy: maximum information in one screen + hover tooltips.

Build Testing Notes (Current)

  • Multiplayer currently runs locally. Launch the exe twice: first = Host, second = Client.
  • Three units available in this build (Light Infantry, Light Cavalry, Archer). Drag & drop to deploy.
  • During turns: left click select, right click move, hold and drag to rotate.
  • To attack: hover enemy unit and right click.
